How it works

Versioned facts and read receipts, in one graph.

write

Facts keep their history

Every fact ("Release 2.4 ships on…") is a relation capped at one current value. A newer statement retires the old one and keeps it as history, so any question can be asked as_of any moment.

read

Every read leaves a receipt

A SAW edge connects each person or agent to each message they read: solid if they interacted, dashed if we only know they're in the channel. People's answers teach the graph who really reads what.

diff

A brief is a traversal

What you believe is the newest version on a message you saw. Compare it with the current version and you have your corrections, ranked by how close they are to your work, with a confidence. No model call.

The product

From "who's behind?" to "who should I tell?"

Corrections, written as diffs

Each person gets a short list of exactly what they're wrong about: the old value, the new one, the message they got it from, the message that changed it, and why they missed it. A button says "news to me" and the graph learns.

The graph behind every fact

Click any fact to see who saw which message, which version each message states, and the missing edge that makes someone stale. Next to it: what a real vector search returns for the same question.

Fix it, with a what-if

Unstale says who still needs to hear a change, which channel reaches them, who needs an @mention because they rarely read it, and drafts the message. Then it shows the corrections that would be left, without writing anything.

For agents

Your agents are readers too.

An agent only knows what it was given. Every change in a channel it doesn't read is a wrong answer waiting for a customer. Connect it and it can ask what in its context is out of date, before it answers.

Built on HydraDB

The graph does the work.

  • Versioned facts. SelfGraph caps each attribute at one current value; a new statement supersedes the old and keeps it readable.
  • Read receipts as edges. SAW edges with a strength, written at ingest, traversed in Cypher.
  • Time travel. Every read takes as_of, including what the graph had learned by then.
  • Self-hostable. One container, open-source HydraDB 0.4.0, about 130 MB of memory.
schema = {
  "relations": [{ "type": "SHIPS_ON",
                  "from": { "max_count": 1 } }]
}
SelfGraph(store=HydraDBStore(uri), schema=schema,
          contradiction="supersede")

// who saw what, and what those messages say
MATCH (p:Entity)-[s:RELATES]->(m:Entity)
      -[a:RELATES]->(c:Entity)
WHERE p.sid = $p AND s.etype = 'SAW'
  AND a.etype = 'ASSERTS'
RETURN c.doc AS claim, s.doc AS saw
