Who is still on the old version?

Unstale keeps every fact's history in a HydraDB graph, along with who saw which version. So it knows who is behind, why they missed it, and who to tell.

How it works

Versioned facts, and read receipts for them.

release:2.4 · SHIPS_ON 
− Mon 29 Jun  Priya · #general
+ Fri 3 Jul   Priya · #release

Facts keep their history

One current value per fact. A newer statement retires the old one and keeps it, so any question can be asked as_of any moment.

SAW edges · Maya 
strong → email to Jordan
weak   → #general
none   → #release  ← the change

Reads leave receipts

An edge from each person or agent to each message they saw: strong if they interacted, weak if they are only in the channel. Weak edges carry a read rate learned from people's answers.

brief · Maya · 08:55 
behind on 4 facts
0 LLM tokens · 1 ms

A brief is a traversal

What you believe is the newest version on a message you saw. Compare it with the current one: that is your corrections, ranked by closeness to your work. One Cypher query per person.

The app

From who is behind to who should be told.

For agents

Your agents are readers too. Most of them are behind.

An agent only knows what it was given, so every change in a channel it doesn't read is a wrong answer waiting for a customer. The demo graph is a live MCP server, read-only on the public deployment.

In our eval a support agent gets 29% of 31 customer questions right from its own knowledge base, and 94% with Unstale's correction block (116 extra tokens). Vector RAG over every channel scores 97%, but needs read access to all of them.

$ claude mcp add --transport http unstale \

Results

The data is simulated, and recall tops out around 0.69 even for a model given the true read rates, because some stale beliefs come from messages nobody can see were read. The Proof panel in the app has the full tables, calibration and limits.

Run it yourself

One container runs the open-source HydraDB engine and the app, and rebuilds the graph at start from a committed cache, so it needs no API key.

docker build -t unstale . && docker run --rm -p 7860:7860 unstale
